## Data integrity note

All observed input data in this project come from published sources. The values for 2027-2029 display-glasses shipments are not invented observations; they are transparent calculations using IDC's published 2026 value, 2030 value, and 41.9% CAGR. Bass-model forecasts are model outputs, not historical observations.
